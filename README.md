# 🇺🇿 TilAI — O'zbek tili raqamli yordamchisi

## Texnologik stack
- Backend: Node.js + TypeScript + Express + Prisma
- Database: PostgreSQL 16, Cache: Redis
- Bot: Telegraf.js
- Mini App: React + Vite + TypeScript + Tailwind
- AI: alohida service layer, backend ichida

## Ishga tushirish
1. `.env.example` dan nusxa oling, nomini `.env` qiling, qiymatlarni to'ldiring
2. `docker compose up -d` — Postgres va Redis'ni ishga tushiradi
3. Keyingi fazalarda backend/bot/miniapp qo'shiladi
